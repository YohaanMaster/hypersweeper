# Hypersweeper
Entirely a vanity project because I thought it would be fun to play, which I decided to upload as well.
4x4x4x4 minesweeper, which follows all the usual adjacency rules. Left click to guess and right click to flag.

## Credits
An idea I had after seeing a thumbnail for 3D minesweeper on youtube, before realising shortly after that it is very much a game that already exists. However, I think that the projection view *might* be unique.
The 4D projection itself is loosely adapted from Thibault Brun's hypercube projection code.
The seeding is done using Mulberry32.
